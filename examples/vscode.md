# `tsrs-doctor vscode` demo

Run on a scratch copy of ky (not a real VS Code profile) whose `.vscode/settings.json` already had a commented setting. tsrs 0.18.0, macOS arm64, 2026-10-22.

```
$ bunx tsrs-doctor vscode
Wrote .vscode/tsrs-tsdk/tsgo and .vscode/settings.json (js/ts.tsdk.path, js/ts.experimental.useTsgo).
Checked: .vscode/tsrs-tsdk/tsgo --version -> Version 7.1.0-dev.20260930.4 (tsrs 0.18.0-ts7.1.0-dev.20260929, microsoft/TypeScript@b85298b6a81f)
Next in VS Code:
  1. Install the TypeScript 7 extension (TypeScriptTeam.native-preview).
  2. Trust the workspace and accept the prompt to use the workspace TypeScript version.
  3. Run "TypeScript 7: Restart Server"; the "TypeScript 7" output channel names the executable.
Undo with: tsrs-doctor vscode --undo

#!/bin/sh
# Generated by tsrs-doctor. VS Code's TypeScript 7 extension runs "<js/ts.tsdk.path>/tsgo --lsp --stdio".
root=$(CDPATH= cd -- "$(dirname -- "$0")/../.." && pwd)
exec "$root/node_modules/.bin/tsrs" "$@"
```
